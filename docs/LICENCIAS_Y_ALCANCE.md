## Qué SÍ incluye este ZIP

Implementaciones originales, escritas específicamente para este proyecto, que ilustran los mismos *tipos de interacción* de un catálogo de diseño: sliders, botones, transiciones, navegación, elementos visuales, simulaciones de estados de IA, etc. La interfaz general y la identidad «MOTION-404 STUDIO» también son nuevas.

## Qué NO incluye

No incluye scraping automático de código privativo ni copias del código fuente, estructura interna, ilustraciones, marcas, imágenes, música, backend, repositorios, assets, o textos comerciales de DesignBookmark, Kokonut UI o SmoothUI. Tampoco incluye sus componentes oficiales ni sus versiones premium; los enlaces a proveedores son referencias, no dependencias.

## Uso y atribución

Puedes modificar y distribuir tus propias implementaciones de este paquete bajo los términos que elijas cuando no incorpores material de terceros sujeto a otra licencia. Las marcas y el contenido original de cada proveedor siguen perteneciendo a sus titulares. Se recomienda mantener atribución clara al catálogo usado como inspiración y comprobar licencias antes de importar código oficial.

## Simulaciones de seguridad

Las demostraciones de confirmación, IA, biometría, voz, tarjetas de pago, firma e invitaciones **no son servicios reales** y nunca deben emplearse como sistemas reales de autenticación, cobro o autorización. El campo de tarjeta solicita solo cuatro dígitos ficticios. No envía datos a ninguna parte.

## Calidad

La cobertura de **84 de 84** se refiere a que cada registro dispone de un renderizador original y visible, no a que se haya certificado una réplica 1:1. Las pruebas automáticas y del navegador dan cobertura a aspectos concretos; no se ha llevado a cabo una auditoría manual completa de accesibilidad WCAG o hardware móvil real.
